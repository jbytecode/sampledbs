\section{About the notes}

These notes cover the basics of SQL using the Northwind database in SQLite.
This document is intended to provide a quick reference for SQL queries and operations, 
and is used in my 1st year information technologies course at Istanbul University. 
The notes include examples of SELECT, UPDATE, DELETE, and INSERT INTO statements, 
as well as the use of the LIMIT clause and various filtering techniques.
The notes also include limited examples of JOIN operations and summary statistics using some 
aggregate functions (e.g., COUNT, SUM, AVG).


\section{The Database Schema}

The database is \texttt{Northwind.sqlite}, which is available to download at

\section{LIMIT}

The \texttt{LIMIT} clause is used to specify the maximum number of records to return from a query. 
It is often used in conjunction with the \texttt{SELECT} statement to limit the number of rows returned.

\section{UPDATE}

Description: Updates the unit price values of the products 
with product IDs 1, 2, 3, 4, and 5 by multiplying their current unit price values by 1.25.

\subsection{Update Unit Prices of Specific Products}
\begin{verbatim}
UPDATE Products
SET UnitPrice = UnitPrice * 1.25
WHERE ProductID IN (1, 2, 3, 4, 5);
\end{verbatim}

\subsection{Increase Units in Stock of Specific Products}


Description: Increases the units in stock values of the products 
with product IDs 1 and 2 by adding 10 to their current units in stock values.

\begin{verbatim}
UPDATE Products
SET 
UnitsInStock = UnitsInStock + 10
WHERE ProductID IN (1, 2);
\end{verbatim}



\subsection{Update Customer Information}

Description: Updates the city and phone number of the customer with a customer ID 
of 1 to 'İstanbul' and '(90) 212 123 45 67', respectively.

\begin{verbatim}
UPDATE Customers 
SET 
City = 'İstanbul', 
Phone = '(90) 212 123 45 67' 
WHERE 
CustomerID = 1;
\end{verbatim}


\section{DELETE}

\subsection{Delete Specific Products}

Description: Deletes the products with product IDs 1, 2, 3, 4, and 5 from 
the Products table.

\begin{verbatim}
DELETE FROM Products
WHERE ProductID IN (1, 2, 3, 4, 5);
\end{verbatim}


\section{INSERT INTO}

\subsection{Insert a New Product}

Description: Insert a new product with the name 'New Product', 
a supplier ID of 1, a category ID of 1, a unit price of 9.99, and 100 
units in stock into the Products table.

\begin{verbatim}
INSERT INTO Products 
(ProductName, SupplierID, CategoryID, UnitPrice, UnitsInStock)
VALUES 
('New Product', 1, 1, 9.99, 100);
\end{verbatim}


\subsection{Insert a New Customer}

Description: Insert a new customer with the name 'New Customer',
a contact name of 'John Doe', a city of 'New York', and a 
country of 'USA' into the Customers table.

\begin{verbatim}
INSERT INTO Customers
(CustomerName, ContactName, City, Country)
VALUES
('New Customer', 'John Doe', 'New York', 'USA');
\end{verbatim}


\section{DROP TABLE}

\subsection{Delete Products Table}

Description: Deletes the Products table from the database if it exists.

\begin{verbatim}
DROP TABLE IF EXISTS Products;
\end{verbatim}
